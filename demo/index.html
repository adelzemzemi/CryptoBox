Browser storage, encrypted.

Save one value twice: once the usual way, once through CryptoBox. Then try to read it back with the wrong password, or after changing the stored bytes. Everything runs in this tab, on this page's own localStorage. Nothing is sent anywhere.

Try to read it back

One read should succeed. The three others must be refused.

    What it does not protect against

    A security library that promises too much is worse than none. These limits are part of the design, and they are written in the threat model.

    Script running in your page

    XSS or a compromised dependency sees the password when it is typed and the value when it is decrypted.

    Rollback and deletion

    An earlier value of the same key, put back in place, still decrypts. Whoever can write can also erase.

    No third-party audit

    The format is checked against OpenSSL and frozen ciphertexts in the test suite, not by an external auditor.
